# Performance baselines

Les fichiers de ce dossier sont des observations versionnées, pas des seuils produit. Chaque
baseline doit préciser le schéma, l'environnement, les paramètres et la provenance du code.

La baseline Phase 0 mesure uniquement le décodage et la validation du manifest en build Release.
Elle prouve le fonctionnement du harness JSON; elle ne mesure ni Parakeet, ni Qwen, ni la latence
de dictée.
